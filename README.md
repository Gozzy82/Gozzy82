### BookRPG

An experimental TypeScript story engine that turns EPUB books into interactive stories.

It started after I jailbroke my e-reader and wanted a thin client: the client handles display and input, while book analysis, AI orchestration, story progression and saves stay on the server.

The current public snapshot builds successfully and its deterministic test suite has **1,120 passing tests**.

[Source code](https://github.com/Gozzy82/book-rpg-public) · [Case study](https://gerko.amsterdam/book-rpg/)
